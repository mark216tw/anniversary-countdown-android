# 紀念日提醒 App 優化待辦事項

## 使用方式

- 每個待辦事項皆使用全域唯一編號 `ACD-001` 至 `ACD-037`，可直接作為 Issue、分支或提交訊息的識別碼。
- 狀態預設為未開始，完成後將 `[ ]` 改為 `[x]`。
- 優先級定義：P0 為資料安全或正確性；P1 為核心功能；P2 為品質與體驗；P3 為擴充功能。
- 詳細背景與設計理由請參閱 [`介面與功能優化建議.md`](介面與功能優化建議.md)。

## P0：資料安全與正確性

- [ ] **ACD-001｜為紀念日資料加入 schema version 與 migration 機制**
  - 類型：資料
  - 驗收：既有版本資料可無損升級；未知版本不會被當成空清單覆寫；migration 有自動化測試。

- [ ] **ACD-002｜防止 JSON 解析失敗造成資料清空**
  - 類型：資料
  - 驗收：解析失敗時保留原始資料並回報錯誤；異常狀態下禁止以空清單自動覆寫。

- [ ] **ACD-003｜建立單筆資料驗證與損壞資料復原策略**
  - 類型：資料
  - 驗收：單筆資料異常不影響其他有效紀念日；使用者可得知異常筆數並匯出原始備份。

- [ ] **ACD-004｜讓 Repository 寫入操作回傳成功或錯誤結果**
  - 類型：資料／架構
  - 驗收：新增、更新、刪除與設定寫入皆有可觀察結果；I/O 失敗不會被靜默忽略。

- [ ] **ACD-005｜建立載入、儲存中、成功與失敗 UI 狀態**
  - 類型：介面
  - 驗收：啟動時不會短暫誤顯示空狀態；儲存成功後才離開編輯頁；失敗時保留草稿並可重試。

- [ ] **ACD-006｜以日曆日計算未指定時間事件的倒數**
  - 類型：日期邏輯
  - 驗收：日期型事件顯示今天、明天或剩餘 N 天，不因當下時刻顯示不完整小時；跨 DST 結果正確。

- [ ] **ACD-007｜修正近期事件醒目提示的日期判斷**
  - 類型：日期邏輯
  - 驗收：未來七個日曆日內的事件皆正確標示；結果不依賴固定 24 小時毫秒數。

- [ ] **ACD-008｜保存編輯頁目的地與未儲存草稿**
  - 類型：導航／狀態
  - 驗收：旋轉螢幕、組態變更與可模擬的程序重建後，仍回到同一頁並保留表單內容。

## P1：核心產品與操作流程

- [ ] **ACD-009｜加入未儲存變更離開確認**
  - 類型：介面
  - 驗收：表單有修改時，工具列返回與系統返回皆提供繼續編輯或捨棄變更；未修改時直接離開。

- [ ] **ACD-010｜修正刪除確認流程並加入復原**
  - 類型：介面
  - 驗收：確認視窗顯示時仍停留在編輯頁；取消後保留內容；刪除成功後可由 Snackbar 復原。

- [ ] **ACD-011｜移除主畫面的「移到背景」操作**
  - 類型：介面
  - 驗收：非典型背景按鈕不再出現；原位置改為搜尋、篩選或更多選單等核心操作。

- [ ] **ACD-012｜加入名稱搜尋**
  - 類型：功能
  - 驗收：可即時依名稱搜尋；清除搜尋可恢復完整清單；空結果有明確提示。

- [ ] **ACD-013｜加入分類與狀態篩選**
  - 類型：功能
  - 驗收：可篩選分類、即將到來與已過期事件；可一鍵清除條件；搜尋與篩選可同時使用。

- [ ] **ACD-014｜重整主畫面卡片與已過期區段**
  - 類型：介面
  - 驗收：名稱、下一次日期與倒數為主要層級；次要資訊可換行；已過期一次性事件置於可收合區段。

- [ ] **ACD-015｜實作每筆事件的提醒設定資料模型與介面**
  - 類型：提醒
  - 驗收：事件可關閉提醒或選擇當天、提前一天、提前一週及自訂時間；重新開啟編輯頁後設定完整保留。

- [ ] **ACD-016｜實作通知權限與 NotificationChannel**
  - 類型：提醒
  - 驗收：Android 13 以上只在使用者啟用提醒時請求權限；拒絕後有設定引導；舊版 Android 可正常運作。

- [ ] **ACD-017｜實作提醒排程、取消與重新排程**
  - 類型：提醒
  - 驗收：新增、修改、刪除事件會同步更新排程；重新開機、系統時間與時區變更後可恢復正確排程。

- [ ] **ACD-018｜讓通知直接開啟對應紀念日**
  - 類型：提醒／導航
  - 驗收：點擊通知可直接進入正確事件；事件不存在時安全返回主畫面並顯示提示。

- [ ] **ACD-019｜在設定頁加入測試通知與提醒狀態診斷**
  - 類型：提醒
  - 驗收：使用者可發送測試通知；頁面會顯示通知權限與受限制狀態，並提供可行處理方式。

- [ ] **ACD-020｜實作 JSON 備份匯出**
  - 類型：備份
  - 驗收：透過 Storage Access Framework 匯出具版本的完整資料；不要求廣泛檔案權限；匯出失敗有錯誤提示。

- [ ] **ACD-021｜實作具預覽與衝突處理的資料匯入**
  - 類型：備份
  - 驗收：匯入前顯示版本、事件數與衝突；可略過、覆蓋或建立副本；匯入失敗不破壞現有資料。

- [ ] **ACD-022｜讓 Widget 點擊開啟對應事件或新增頁**
  - 類型：Widget／導航
  - 驗收：有事件時開啟目前顯示的事件；無資料時開啟新增頁；PendingIntent 身分不會導向錯誤項目。

- [ ] **ACD-023｜補齊資料、日期與核心流程自動化測試**
  - 類型：測試
  - 驗收：涵蓋損壞 JSON、migration、I/O 失敗、日期型與時間型倒數、DST、草稿恢復及刪除復原。

## P2：可用性、無障礙與品質

- [ ] **ACD-024｜改用 Material 3 日期與時間選擇器**
  - 類型：介面
  - 驗收：Picker 可跟隨 App 深淺色與主題；既有日期、時間、取消及確認行為不退化。

- [ ] **ACD-025｜讓空狀態與表單支援小螢幕及大字體捲動**
  - 類型：響應式
  - 驗收：橫向、小螢幕及字體倍率 2.0 下，所有內容與主要操作仍可到達。

- [ ] **ACD-026｜將固定三欄選項改為自動換行版面**
  - 類型：響應式
  - 驗收：分類、主題色與顯示模式在各種寬度及字體倍率下不裁切、不重疊。

- [ ] **ACD-027｜建立手機與平板響應式版面**
  - 類型：響應式
  - 驗收：依 Window Size Class 切換合適版面；平板表單有最大寬度；橫向不會產生過度留白或擁擠。

- [ ] **ACD-028｜補足色彩選項與開關的無障礙語意**
  - 類型：無障礙
  - 驗收：TalkBack 可讀出色彩名稱與選取狀態；沒有重複或無作用的可點擊節點；開關狀態清楚可知。

- [ ] **ACD-029｜確保 App 與 Widget 的文字色彩對比**
  - 類型：無障礙
  - 驗收：自訂色不直接造成低對比文字；主要文字符合 WCAG AA 目標；深淺色與預設色盤皆完成檢查。

- [ ] **ACD-030｜將所有使用者文案移至 Android 字串資源**
  - 類型：在地化
  - 驗收：Kotlin 與 Widget 不再硬編碼使用者可見文案；數量使用 plurals；日期與時間依 Locale 格式化。

- [ ] **ACD-031｜實作可搜尋的固定時區選擇器**
  - 類型：功能
  - 驗收：可依城市或時區搜尋；顯示 UTC offset 與友善名稱；儲存 IANA zone ID；無效時區不會靜默退回。

- [ ] **ACD-032｜讓 Widget 依尺寸調整顯示內容**
  - 類型：Widget
  - 驗收：小尺寸不裁切並顯示名稱與倒數；大尺寸可顯示額外資訊；調整尺寸後立即更新版面。

- [ ] **ACD-033｜改善 Widget 預覽與重新整理操作**
  - 類型：Widget
  - 驗收：選擇器預覽接近實際內容；提供可存取的重新整理操作；更新不造成不必要的頻繁背景工作。

- [ ] **ACD-034｜建立 CI 品質檢查流程**
  - 類型：工程品質
  - 驗收：每次提交自動執行單元測試、Lint 與 prerelease build；失敗會阻止合併；結果可在 CI 介面查閱。

- [ ] **ACD-035｜完成正式發布與備份政策設定**
  - 類型：發布／隱私
  - 驗收：使用正式唯一套件名稱與簽章；版本及 Build ID 可追溯；Android Backup 規則與隱私說明一致。

## P3：擴充功能

- [ ] **ACD-036｜加入紀念日分享功能**
  - 類型：分享
  - 驗收：可透過系統 Sharesheet 分享文字；使用者可選擇是否包含日期、時間與分類；取消分享不影響 App 狀態。

- [ ] **ACD-037｜加入封存、批次管理與月曆檢視**
  - 類型：進階功能
  - 驗收：一次性過期事件可封存與還原；可批次封存或刪除；月曆可清楚顯示並開啟指定日期的事件。

## 建議里程碑

| 里程碑 | 建議納入項目 | 目標 |
| --- | --- | --- |
| M1 正確性修正版 | ACD-001 至 ACD-010、ACD-023 的 P0 測試 | 資料不會靜默遺失，日期計算與編輯流程可靠 |
| M2 提醒功能版 | ACD-011 至 ACD-019、ACD-022 | 完成搜尋與真正的系統提醒，通知與 Widget 可直達事件 |
| M3 備份與品質版 | ACD-020、ACD-021、ACD-024 至 ACD-035 | 可備份還原，介面具響應式、無障礙與發布品質 |
| M4 擴充體驗版 | ACD-036、ACD-037 | 提供分享與進階資料管理能力 |

## 完成定義

每個待辦事項完成前至少應符合以下條件：

- 符合該項目的驗收條件。
- 新增或更新必要的單元測試、UI 測試或裝置測試。
- 通過既有單元測試、Lint 與相關建置。
- 使用者可見行為已同步更新 README 或使用說明。
- 不會破壞既有紀念日資料，涉及格式變更時具備 migration 測試。
