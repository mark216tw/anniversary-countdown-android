# 紀念日提醒使用說明

## 新增紀念日

點選主畫面右下角的「＋」，輸入紀念日名稱並選擇日期。時間為選填；未指定時間時，App 會以日期為單位計算，並在當天顯示「就是今天」。

## 重複方式

### 不重複

只在指定日期到期一次。日期經過後會移至未到期項目的下方，並顯示已經過的時間。

### 每月

以輸入日期的日數作為每月重複基準。若該月沒有指定日期，會使用當月最後一天。

範例：

- 設定每月 31 日。
- 4 月會在 4 月 30 日到期。
- 非閏年的 2 月會在 2 月 28 日到期。

### 每年

以輸入日期的月與日計算下一次到期時間。生日可以輸入實際出生年份，App 仍會自動顯示下一次生日。

若日期為 2 月 29 日，可指定非閏年使用：

- 2 月 28 日。
- 3 月 1 日。

## 時區模式

### 跟隨手機時區

日期與時間會依目前手機時區解讀。適合生日、當地節日及希望在所在地相同鐘面時間到期的事件。

### 固定時區

儲存建立紀念日時的時區。跨國旅行或變更手機時區後，仍以原時區計算實際到期時刻。適合航班、遠端活動或有明確舉辦地點的事件。

日光節約時間切換期間若指定時間不存在，系統會將時間順延到下一個有效時刻；若時間重複，會採用 Java 時間系統的較早偏移量。

## 分類與顏色

可選擇生日、愛情、家庭、旅行、工作或其他分類。每筆紀念日也可透過彩虹色相滑桿選擇獨立識別色，方便從主畫面快速辨識。

## App 外觀

在主畫面右上角點選齒輪圖示開啟「設定」，可選擇跟隨系統、淺色或深色顯示模式。主題提供暖陽黃、珊瑚紅、活力橘、青草綠、天空藍與葡萄紫，也可使用彩虹色相滑桿自訂。主題色會立即套用至主畫面、設定頁、狀態列與系統導覽列；桌面小工具則以目前顯示紀念日的識別色呈現，沒有資料時才沿用 App 主題色。

## 桌面小工具

從 Android 桌面的小工具選單加入「紀念日提醒」。小工具會優先顯示最近的未到期紀念日，若沒有未到期項目則顯示最近一筆既有資料。背景、強調色與文字色會由該紀念日的識別色產生，並自動維持文字對比。

小工具更新時機：

- 新增、編輯或刪除紀念日。
- 切換 App 主題色或顯示模式。
- 系統日期、時間或時區變更。
- 系統定期更新，最長間隔約 30 分鐘；實際時間由 Android 系統決定。

## Prerelease 版本注意事項

GitHub Release 提供的 APK 是測試發行版本，不是正式發布版本。APK 已啟用 R8 與資源壓縮，但使用 Android Debug 金鑰簽署，僅建議用於功能試用與測試。
