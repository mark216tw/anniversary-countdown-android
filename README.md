# 紀念日提醒 Android

一款簡單、容易操作的 Android 紀念日提醒 App。可記錄生日、週年、旅行與其他重要日期，並在主畫面及桌面小工具查看下一個即將到來的紀念日。

## 功能特色

- 建立、編輯與刪除多個紀念日。
- 日期可選擇是否指定時間，倒數不顯示秒數。
- 支援不重複、每月重複與每年重複；每年紀念日會在主畫面顯示已經過的完整年數與天數。
- 依下一次到期時間排序，最近的紀念日優先顯示。
- 分類包含生日、愛情、家庭、旅行、工作與其他，每個分類皆有對應圖示。
- 每個紀念日可從六種暖色預設色選擇識別色，也可透過彩虹色相滑桿自訂。
- 提供暖陽黃、珊瑚紅、活力橘、青草綠、天空藍與葡萄紫六種 App 主題，亦可自訂色相。
- 顯示模式支援跟隨系統、淺色與深色，狀態列與底部系統導覽列會同步切換。
- 每筆紀念日可個別啟用通知，並以全站規則設定提前天數、當天提醒及通知時間。
- 支援 Android 通知權限引導、測試通知，以及重新開機、時間或時區變更後自動恢復排程。
- 提供單筆版及 4×2 雙筆版桌面小工具，並以最近紀念日的識別色呈現完整色系；資料變更時會立即更新，鈴鐺會標示提醒狀態。
- 資料儲存在裝置本機，不需建立帳號。

## 系統需求

- Android 8.0（API 26）以上。
- 桌面小工具的外觀可能因手機品牌與桌面啟動器而略有不同。

## 安裝 Prerelease APK

1. 前往本專案的 [Releases](https://github.com/mark216tw/anniversary-countdown-android/releases) 頁面。
2. 開啟標示為 Pre-release 的 `v1.3.0-prerelease`。
3. 下載 `app-prerelease.apk` 並在 Android 裝置上安裝。

> [!WARNING]
> Release 內提供的是測試發行版本，不是正式發行版本。它已啟用 R8 與資源壓縮，但仍使用 Android Debug 金鑰簽署，僅供功能測試，請勿視為正式版散布。

## 基本操作

1. 點選右下角的「＋」新增紀念日。
2. 輸入名稱並選擇日期，可設定時間、重複方式、通知、分類、顏色及時區。
3. 按下「儲存」後，紀念日會依下一次到期時間自動排序。
4. 點選既有卡片可編輯或刪除。
5. 點選主畫面右上角的齒輪圖示，可設定通知規則、測試通知，並切換 App 主題色與顯示模式。

設定與編輯紀念日使用整頁介面；按下左上角或系統返回鍵可回到主畫面。

## 桌面小工具

1. 長按 Android 桌面空白處。
2. 開啟「小工具」或「Widgets」。
3. 找到「紀念日提醒」，選擇單筆版或 4×2 雙筆版。
4. 將需要的小工具拖曳至桌面。

單筆版會顯示最近一筆未到期紀念日，沒有未到期資料時會顯示最近一筆既有資料。4×2 雙筆版只顯示最近兩筆未到期紀念日；若只有一筆，第二列會保持空白，不會以已到期項目補足。兩種小工具皆顯示分類圖示與提醒鈴鐺，並由最近紀念日的識別色衍生背景、強調色與高對比文字；靜音鈴鐺表示事件已設定提醒，但 App 或系統通知目前關閉。沒有資料時則沿用 App 主題色。小工具會在紀念日、顯示模式、提醒設定變更及系統定期更新時重新整理，點選後可開啟 App。

## 通知與提醒

- 在紀念日編輯頁開啟「啟用通知」。
- 在設定頁統一選擇提前 1、3、7、14 或 30 天提醒，以及是否在當天提醒。
- 通知採一般準時模式，Android 省電機制可能使通知延後數分鐘。
- Android 13 以上需允許通知權限；若有已啟用提醒的紀念日，App 啟動時會檢查並提供開啟引導。
- 設定頁可發送測試通知，通知被封鎖時可前往系統設定處理。

## 日期與時區規則

- 每月重複遇到不存在的日期時，使用該月最後一天。例如每月 31 日在 2 月會使用 2 月最後一天。
- 每年重複的 2 月 29 日，可選擇非閏年使用 2 月 28 日或 3 月 1 日。
- 每年重複會在主畫面顯示「經過了 x 年 x 天」，原始日期尚未到達時不顯示；桌面小工具只保留下一次倒數。
- 只設定日期的紀念日在到期當天顯示「就是今天」。
- 「跟隨手機時區」會在旅行後維持當地相同的日期與鐘面時間。
- 「固定時區」會保留建立時的時區，在跨國旅行後仍維持原地的實際到期時刻。
- 日光節約時間造成指定時間不存在時，Java 時間系統會順延至下一個有效時間。

## 開發與建置

本專案使用 Kotlin、Jetpack Compose、Material 3、DataStore 與傳統 Android App Widget。

環境需求：

- JDK 17
- Android SDK 36
- Android Studio 或 Gradle Wrapper

Windows 建置指令：

```powershell
.\gradlew.bat testPrereleaseUnitTest lintPrerelease assemblePrerelease
```

macOS 或 Linux：

```bash
./gradlew testPrereleaseUnitTest lintPrerelease assemblePrerelease
```

建置後的 Prerelease APK 位於：

```text
app/build/outputs/apk/prerelease/app-prerelease.apk
```

## 測試

單元測試涵蓋：

- 倒數文字不顯示秒數。
- 下一次到期時間排序。
- 4×2 小工具只選取最近兩筆未到期紀念日。
- 每月月底日期調整。
- 每年生日計算。
- 每年紀念日的完整年數與週年後天數。
- 2 月 29 日非閏年規則。
- 未指定時間的當日顯示。
- 固定時區下的跨國旅行計算。
- 提前與當天提醒排程，以及跨月重疊提醒。
- 啟動通知引導的顯示條件。

## 隱私

目前版本不需要網路權限，紀念日與 App 設定皆保存在裝置本機。移除 App 或清除應用程式資料可能會刪除所有紀念日，使用前請自行評估 Prerelease 版本的資料保存風險。
